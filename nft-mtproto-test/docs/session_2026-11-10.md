## Решения владельца проекта

- Источник данных о владельце — kartoshka.free; see.tg не запрашиваем, повторных согласований нет.
- Двухэтапная фильтрация (§20) — окончательно.
- Владелец учитывается только с username.
- Скрытый владелец — только в локальном логе.
- Три потока: NFT-уведомления, служебные логи (`LOG_GROUP_ID`), локальный лог.
- Работаем с платными запросами Kartoshka.

## Решения, принятые в разработке (можно пересмотреть)

- Уведомления нового пользователя выключены по умолчанию.
- `DAILY_API_BUDGET_TON` по умолчанию 0 в коде; рабочий бюджет задаётся в `.env`.
- Квота в начале суток узнаётся бесплатным `/v1/ping` (квота общая на все приложения аккаунта).
- Backfill не рассылает уведомления по старым листингам, результат — в «Мои совпадения».
- `listing_date` = время обнаружения; `listing_identity = slug:эпизод`.
