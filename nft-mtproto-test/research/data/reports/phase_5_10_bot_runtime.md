# Отчёт: Фазы 5–10 — бот, уведомления, админка, тесты, надёжность, документация

Дата: 2026-11-10.

## Сделано
- **Бот** (aiogram 3.31, `app/bot/`): `/start`, `/help`, `/search`, `/stats`, `/settings`, `/filter`, меню (новые листинги с пагинацией, мои совпадения, поиск, настройки, статистика, помощь), поиск свободным текстом. Карточка: коллекция, номер, цена, модель, фон, паттерн, username и Telegram ID если есть, статус приватности (скрытый — явно), ссылка `t.me/nft/<slug>` только для проверенного slug, строка «Данные о владельце: see.tg». Поиск только по локальной БД. Роутеры создаются фабриками (`build_router`) — бот можно перезапускать.
  - Решение: у нового пользователя уведомления **выключены**, пока он не включит их в настройках. Иначе без фильтров он получал бы каждый листинг рынка, а его пустой фильтр запускал бы запрос владельца для всех листингов.
- **Уведомления** (`app/services/notifications.py`): отправка строк `notifications` (их создаёт этап 2), `RetryAfter` → ожидание и повтор, заблокировавший бота пользователь → `FAILED` и `is_active=False`, прочие ошибки — 3 попытки, параллельно не более 5, без дублей. Алерты администраторам (бюджет, 402, 401) не ломают вызывающий код.
- **Админка** (`app/bot/admin.py`): `/admin` (MTProto, сканер, Kartoshka, очередь, пользователи, уведомления, ошибки, расходы, компоненты), `/errors`, `/retry_failed`, `/retry_deferred`, `/resume_api`, `/restart <компонент>`. Для обычных пользователей команды молча игнорируются.
- **Запуск** (`app/main.py`, `app/supervisor.py`): `python -m app`, миграции, восстановление очереди, статус в логе, компоненты scanner/workers/notifications/bot/backup как независимые задачи, автоперезапуск упавшего компонента с паузой 5 с → 5 мин, `FatalComponentError` (например, неавторизованная сессия) — без перезапуска. Корректная остановка по Ctrl+C/SIGTERM.
- **Резервные копии** (`app/services/backup.py`): онлайн-бэкап SQLite раз в сутки, 7 копий, восстановление.
- **Документация**: `README.md` (9 пунктов §14 + команды бота), `docs/database.md`, `research/data/reports/kartoshka_api_integration.md`.
