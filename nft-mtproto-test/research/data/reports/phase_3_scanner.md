# Отчёт: Фаза 3 — MTProto Listing Scanner (T3.1–T3.4)

Дата: 2026-11-10. T3.5 (очередь) по §17 выполняется после провайдера.

## Сделано
- `app/mtproto/client.py` — `MTProtoClient`: allowlist только read-методов (`GetStarGifts`, `GetResaleStarGifts`, `GetUniqueStarGift`), пауза 1,5 с между запросами, FloodWait до 120 с — ожидание, дольше — `FloodWaitTooLong`; сетевые ошибки — переподключение (не более 3 раз) и не более 3 попыток запроса; без интерактивного входа (`NotAuthorized`). Собственная копия сессии `sessions/app.session` из `sessions/mtproto_test.session`.
- `app/mtproto/scanner.py` — `ListingScanner`: типы подарков с листингами (`GetStarGiftsRequest`, кэш на час), первые `pages_per_type` страниц по 100, защита от вечного цикла (пустая страница с `next_offset` или повтор offset), `scan_state` на каждый тип, одна ошибка типа не останавливает цикл, FloodWait/сеть — остановка цикла. Каждая страница и downstream-хук (этап 1 фильтрации) — в одной транзакции.
- `app/services/listings.py` — NFT отдельно от листинга, `listing_identity = '{slug}:{episode}'`, события `NEW_LISTING`, `PRICE_CHANGED` (по цене в валюте продавца), `LISTING_UPDATED` (вернулся из UNKNOWN), `LISTING_INACTIVE` (только после полного просмотра типа или смены продавца), `UNKNOWN_STATE` (не виден 24 ч). Продажа не объявляется никогда.

## Тесты
`tests/test_scanner.py` (16): новые NFT без дублей при повторе, пагинация, защита от цикла, пустой тип, смена цены, дрейф конвертации ≠ смена цены, исчезновение → INACTIVE только после полного скана, частичный скан → UNKNOWN, эпизоды 1→2→3, откат транзакции при ошибке хука, клиент: запрет записи, FloodWait короткий и длинный, переподключение и отказ, запрет интерактивного входа, остановка цикла при ошибке MTProto.

`pytest tests` — 59 passed.

## Ограничения
- Опрос первой страницы: листинг, ушедший со страницы 1 крупного типа, становится UNKNOWN через 24 ч, а не INACTIVE.
- Снятие и повторное выставление тем же продавцом между сканами неотличимо от продолжения листинга.
- Живое подключение не проверялось в этой фазе — T11.1.
