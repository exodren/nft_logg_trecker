## Ключевые решения

- `listing_date` = время обнаружения (в `StarGiftUnique` нет даты листинга).
- `listing_identity = slug:эпизод` (нет ID листинга); новый эпизод — после `INACTIVE` или смены продавца.
- `LISTING_INACTIVE` только после полного просмотра типа; иначе через 24 ч — `UNKNOWN`. Продажа не объявляется.
- Owner lookup — только для листингов, прошедших этап 1 (§20); без данных владельца нет совпадений по критериям владельца.
- Kartoshka: поля ответа не угадываются; провайдер не вызывается, пока маппер не подтверждён реальными ответами.
- `DAILY_API_BUDGET_TON=0` по умолчанию — только бесплатная квота; квота узнаётся бесплатным `/v1/ping`.
- Уведомления пользователя по умолчанию выключены (opt-in).
- Деньги — `Decimal`, на SQLite хранятся текстом.

## Известные ограничения

1. **Kartoshka не подключён**: нужен токен, затем `python -m scripts.capture_kartoshka_fixtures …` (бесплатная квота) и маппер полей по реальным ответам.
2. **Бот не запускался вживую**: нужен `BOT_TOKEN`.
3. Сканер опрашивает первую страницу каждого из 124 типов (~3 мин на цикл при 1,5 с на запрос): листинги, ушедшие со страницы 1 крупного типа, становятся `UNKNOWN`, а не `INACTIVE`.
4. Снятие и повторное выставление тем же продавцом между сканами неотличимо от продолжения листинга.
5. Пустой фильтр пользователя с включёнными уведомлениями означает запрос владельца для каждого нового листинга — это сдерживает только бюджет.
6. Backfill проверяет 500 последних активных листингов.
7. Пороговые значения (24 ч до `UNKNOWN`, 1 запрос/с к Kartoshka, 30 с базовый backoff) — константы в коде, помечены `ponytail:`.

## Как запустить

См. `README.md`: `pip install -r requirements.txt`, заполнить `.env` по `.env.example`, `python test_gift.py` (один раз), `python -m app`; тесты — `pytest`.

## Следующие шаги

1. Добавить `BOT_TOKEN` и `ADMIN_TELEGRAM_IDS` в `.env`, запустить `python -m app`, проверить критерий 11.
2. Получить `KARTOSHKA_API_TOKEN`, снять 4 ответа скриптом, написать проверенный маппер (K4.4), закрыть критерии 5–8.
3. Сквозной прогон по 15 критериям на живых данных и обновление этого отчёта.
